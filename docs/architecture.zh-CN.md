# 运行架构说明

[English](architecture.md)

以 flask_app/ 或 molecule_generator/ 开头的路径以项目根目录为基准；其他模块名及 static/ 路径以 flask_app/ 为基准。

## 模块职责

- flask_app/app.py：路由、浏览器归属校验、一次性会话、绘制计时、证据检查点、结构校验和报告保存。
- security_validation.py：校验证据格式、时间顺序、化学结构，以及检查点证据只能追加、不能改写的约束。
- security_scoring.py：对通过服务端校验的证据进行行为评分。
- security_store.py：通过 SQLite 持久化保存行为指纹，防止重复使用同一份绘图证据。
- attention_check.py / attention_image.py：服务端选择目标的一次性限时点击验证。随机延迟 3～8 秒后显示提示，点击窗口为 5 秒。目标选择不受客户端提供的按钮清单控制。
- static/attention-check.js：把实际工具栏点击映射到图集坐标。所有候选按钮使用相同的图片处理方式，只有一个图集分块包含可见像素；验证点击不会改变分子绘图。
- static/usage-monitor.js：实时证据采集、结果面板、PNG 导出和绘制回放。
- static/quick-atoms.js：原子工具栏随机排序、可配置元素干扰、冷却及原生工具状态同步。
- static/disable-canvas-paste.js：保护手工绘图流程，限制导入和粘贴。
- molecule_generator：碳骨架枚举、CH2 位点替换、RDKit 校验与去重，也支持命令行调用。

## 语言与图片资源

首页默认英文；?lang=zh 可显式选择中文。切换语言时会重新加载编辑器并创建新挑战。

挑战语言保存在服务端，创建会话时按该语言生成注意力验证图。缺省或不支持的语言值使用英文。

attention_assets/left.png、right.png 和 down-0.png 至 down-7.png 是中文图片；同名的 -en.png 文件是英文图片。所有分块均为 360×128 的 RGBA 图片，并使用相同的目标坐标。

英文图片已经预生成，运行时不需要额外安装字体。

## 证据与计时

协议 v3 默认每 1.5 秒提交累计证据，并使用一次性回执。最终报告必须与已经封存的实时历史一致。

防重放指纹不包含答案和会话身份；浏览器 Cookie 将挑战绑定到同一浏览器。在正确配置的 HTTPS 环境下会使用 Secure Cookie。服务端重新计算轨迹统计，并校验最终 MOL 与 SMILES。

点击开始检测后启动绘制计时。默认情况下，8 个重原子的上限为 30 秒，每增加或减少 1 个重原子相应增减 5 秒；用时不超过 10 秒会触发过快判定。参数位于 config.py。限时点击验证和绘制计时是相互独立的要求。

accepted: true 表示服务端判定通过。仅有 HTTP 200 或 ok: true 不代表通过验证。上传失败时不会退回使用本地结果宣称成功。

## 当前边界

客户端事件不是不可伪造的真人证明。实时构造自洽证据或使用浏览器自动化仍可能模拟交互；分析图片像素也可能定位注意力验证目标。

项目尚未证明能够普遍防御这类自动化，也未提供业务侧验证码凭据签发 / 核销服务、分布式会话或分布式限流。
